# Proyecto_Stylos_Madys
Salón de belleza capilar. HTML, CSS, JavaScript, PHP y MySQL (XAMPP).

## Cómo ejecutarlo
1. Copia esta carpeta en `C:\xampp\htdocs\`
2. Inicia Apache y MySQL en XAMPP
3. Importa `stylos_madys.sql` en phpMyAdmin
4. Abre http://localhost/Proyecto_Stylos_Madys/ (redirige a View/index.html)
